# FMDatasetSparkChallenge

## Project Overview
This project processes and analyzes the Last.fm dataset using Spark.

## Data Handling
The `data/` folder contains input and output data files. These files are excluded from version control to keep the repository lightweight.

### Instructions to Obtain Data
1. Download the dataset from the [Last.fm Dataset](https://www.last.fm).
2. Place the dataset in the `data/input/` folder.

### Output Data
Processed data will be saved in the `data/output/` folder.

## Setup and Usage
1. Clone the repository.
2. Follow the instructions in the `Dockerfile` or `pyproject.toml` to set up the environment.
3. Run the `main.py` script to process the data.
